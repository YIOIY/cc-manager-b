# 账号卡片紧凑化（短设计）

## 目的
账号列表的平台卡片太高、信息重复、长值被截断，有封禁提示的卡片比其他卡片高出一截。目标是同样的信息用更少的高度展示，各卡片高度基本一致。

## 目标 / 非目标
- 目标：卡片高度约减半；去掉重复字段；用量一眼可读；异常提示不撑高卡片。
- 非目标：不改接口和数据；不删任何信息（完整资料仍在「查看详情」）；仪表盘另行处理。

## 方案
- A（采用）：重排展示——头部合并身份信息，用量改成进度条，资料压成一行摘要（悬停看全部），异常提示单行。
- B：保留更多资料字段（如套餐起止独占一行）。更直观，但卡片仍偏高。用户选择 A。

## 设计
1. 头部：状态点 + 别名 + 上号状态；第二行「邮箱 · ID 平台账号ID」；标签行：套餐、运行状态、所属/未分配、代理、平台已移除、已归档、平台标签（tags）。去掉恒为 claude 的平台标签；「来自平台」改为别名悬停提示。
2. 用量（PlatformUsageBlock）：5h / 7d 两行进度条，百分比 + 重置时间（同日只显示时分）；进度条按 usageTone 着色；一行「$花费 · 入 x · 出 y」，Token 用 K/M 缩写（悬停看精确值）；观察时间缩到小字，过期时标黄。
3. 资料摘要：套餐起止、注册地、支付方式、设备、注册时间、充值日期、质保期合并为一行，悬停显示全部字段；与本地不一致时显示「≠本地」标记。
4. 异常：封禁原因单行省略，悬停看全文；重新授权提示保留单行。
5. 底部：左侧创建时间，右侧操作按钮。
