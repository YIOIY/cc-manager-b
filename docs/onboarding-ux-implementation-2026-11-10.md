日期：2026-11-10。已按原交互方案完成代码修改；未加入 localhost / oa授权2。

## 已落地

1. **连接账号**：先选择平台和代理，再登录 Claude。支持已有代理、页内填写新代理并点击“保存并使用”；自动分配禁用并标注“待接入”。新代理未保存不能继续。
2. **补充资料**：展示已连接账号摘要，仅展开未获取的资料。凭证、可选资料折叠，密码、Token 和代理认证地址默认隐藏。邮箱未从 OAuth 返回时可手动补填。日期和设备 ID 不编造。
3. **确认上号**：只读核对账号、订阅周期、平台及代理，敏感信息仅显示已填写。点击“确认并上号”才发请求；入队提示为“已提交，等待平台处理”。
4. 返回保留输入；更换账号清除旧账号资料；更换代理要求重新授权；无邮箱或邮箱冲突的替换导入被拦截。已保存凭证被服务端拒绝时返回重新授权，保留业务资料及错误请求编号。
5. 未提交退出会提醒，重复点击不重复提交；字段修改后清除该字段的旧错误；桌面和小屏均固定标题及操作区，中间内容可滚动。

## 产物与恢复

项目内 `.local-run/onboarding-20261110/` 保存：

- `changes.patch`：本次修改差异；共享文件基线保留其他任务的变更。
- `manifest.json`：原始、恢复基线及最终文件 SHA256。
- `original/`、`rollback-base/`、`final/`：原始、可恢复基线和最终版本。
- `logs/`：实际测试命令、原始输出和退出状态。
- `screenshots/`：连接、补资料、确认及移动端截图。
- `restore.py`：显式指定目标目录，先核对所有最终 SHA256，再恢复本次涉及的文件；遇到后续修改即拒绝覆盖。

仅检查可否恢复（不修改文件）：

```sh
python3 .local-run/onboarding-20261110/restore.py --root /Users/disaster/GoProject/cc-manager
```

确认需要撤销本次源码改动时，在同一命令后加 `--apply`，随后重新运行 `make build`。此操作只恢复源码，不回滚数据库或删除已创建代理。恢复脚本在额外副本上执行验证，保留当前工作区的最终实现；结果见 `logs/restore-verification.log`。
