## 关键决策

| 决策 | 说明 |
| --- | --- |
| 页面填写优先 | 页面表单为主要入口；JSON 导入用于回填和批量录入，两者共用校验与上传逻辑 |
| 保存与上传分开 | 草稿允许缺项；提交平台必须通过服务端预检 |
| 首版使用已有凭证 | 支持逐字段填写和导入完整凭证；自动授权作为受能力开关控制的后续功能 |
| 不承诺账号密码即可自动上号 | 平台要求额外的组织、设备及验证字段，其生成规则仍需确认 |
| 本地管理与平台管理分开 | 本地编辑、归档、换代理不意味着远端同步成功 |
| 上传受理与账号可用分开 | HTTP 成功仅代表平台接收；后续追踪平台验证和运行状态 |
| 请求统计与金额分开 | 实时接口用于请求量、Token、成功率和状态；金额使用离线账单 |
| 异步任务采用轮询 | 首版用持久任务队列和前端轮询，不引入 Redis、消息总线或 WebSocket |
| 所有秘密留在后端 | 密码、OAuth Token、OpenAPI Token、代理密码加密保存，响应与日志脱敏 |

## 事实与设计的区分

- **已核实**：来自 2026-11-04 在用户 Chrome 中读取的平台页面、OpenAPI 文档和自查指引。见平台对接说明。
- **本地设计**：本项目拟实现的 API、状态机、数据表、页面和调度策略，可以通过设计评审调整。
- **待确认**：没有平台公开文档支持的能力。不得通过猜测参数、内部接口或虚构字段来补齐。

平台尚未进行真实账号上传、额度查询或账单查询实测。因此，已核实指“文档已读取”，不等同于“真实联调通过”。
